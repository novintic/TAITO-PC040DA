A reproduction of the TAITO PC040DA digital-to-analog converter hybrids used in the videocircuitry on some TAITO boards like Bubble Bobble.

the simpler version uses a weighted resistor- network with more or less common values. It works well on Bubble Bobble.

There's also a version with an OPamp to amplify the output. This version has not really been tested as the one without seems to just work well..
